## What belongs in this folder

Widget docs for inventory, stock, warehouse, and inventory-history UI units.

## Documentation rules

1. One file per widget: `WIDGET_<NAME>.md`.
2. Copy `/docs/templates/WIDGET_TEMPLATE.md`.
3. Prefer linking Inventory / Inventory History modules over copying their docs.
4. Do not invent widgets.

## Naming conventions

- `WIDGET_<NAME>.md`
- SCREAMING_SNAKE_CASE after `WIDGET_`
