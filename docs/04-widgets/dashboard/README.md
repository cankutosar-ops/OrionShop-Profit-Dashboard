## What belongs in this folder

Widget docs for UI units that primarily appear on the Dashboard surface.

## Documentation rules

1. One file per widget: `WIDGET_<NAME>.md`.
2. Copy `/docs/templates/WIDGET_TEMPLATE.md`.
3. Link parent module and related ADRs/APIs; do not paste module docs here.
4. Do not create files for widgets that do not exist yet.

## Naming conventions

- `WIDGET_NET_SALES.md` (example pattern only)
- SCREAMING_SNAKE_CASE after `WIDGET_`
